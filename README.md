# Bash Firefox Search

A simple Bash script that allows you to search the web directly from the terminal using Firefox.

## Features

- Search the web directly from the terminal
- Opens search results in Firefox
- Simple Bash implementation
- Lightweight and easy to use

  ## *You can also replace the firefox command with google or whatever the search engine your prefer, I will update the bashcode to accomodiate more. ON TOP OF ALL MAKE SURE THEY ARE INSTALLED ON YOUR MACHINE*
